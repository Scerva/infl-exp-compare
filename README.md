# Which Measure of Inflation Expectations Does the Federal Reserve Respond to Most?

A reproducible Python research pipeline that combines multiple measures of U.S.
inflation expectations with Federal Reserve communications, converts Fed text into
quantitative hawkish/dovish monetary-policy stance measures (not generic
sentiment), and estimates which inflation-expectations indicators are most
associated with subsequent changes in Fed communication.

**This project makes predictive-association claims, never causal claims.** See
[Limitations and identification caveats](#limitations-and-identification-caveats).

## Quick start

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -e .
cp .env.example .env   # fill in FRED_API_KEY (free: https://fred.stlouisfed.org/docs/api/api_key.html)

python scripts/01_download_expectations.py      # ~1 min
python scripts/02_download_fed_text.py           # ~5-15 min (1996-present; ~1,900 pages)
python scripts/03_build_stance_scores.py         # ~2 min
python scripts/build_annotation_sample.py        # ~1 min (optional: human validation set)
python scripts/04_build_model_panel.py           # ~10 sec
python scripts/05_run_descriptives.py            # ~10 sec
python scripts/06_run_models.py                  # ~30 sec
python scripts/07_run_robustness.py              # ~10 sec
python scripts/08_export_paper_outputs.py        # ~5 sec
```

Every stage writes to `data/processed/*.parquet` and `output/{tables,figures,
regressions}/`; each script is independently re-runnable and reads only the
previous stage's parquet outputs, so you can inspect intermediate state at any
point. Run `pytest` (see [Testing](#testing)) before trusting a modified
pipeline.

For the optional zero-shot NLI / FinBERT robustness models (Model B/C, spec
section 7), see [Transformer stance models](#transformer-stance-models-optional).

## What this answers

`output/research_summary.md` (regenerated by stage 8 from live table data, never
hand-written) answers, with real numbers:

1. Which *individual* measure is most associated with Fed stance changes?
2. Which *source family* (household/professional/market/business/model)?
3. Short- or long-horizon expectations?
4. Do speeches and collective FOMC communications differ?
5. Do policymakers respond differently when families diverge?
6. Which measures are most often directly cited?
7/8. How much does the answer move with macro controls / across regimes?

...and explicitly separates "most mentioned" from "most predictive" from
"largest coefficient" from "strongest release-event response" -- spec section 32
is emphatic these are not necessarily the same measure, and in this run they
are not.

## Data sources

Full catalog with provider/frequency/horizon/target-anchor metadata is in
`config/sources.yaml` and exported as `output/tables/table1_source_catalog.csv`.

| Family | Series | Source |
|---|---|---|
| Market | T5YIE, T10YIE, T5YIFR | FRED (TIPS breakevens -- inflation *compensation*, not pure expectations; contains risk/liquidity premia) |
| Model | EXPINF1/5/10/30YR | FRED (Cleveland Fed model) |
| Model/professional | ATSIX (3-120mo curve) | Philadelphia Fed (Aruoba Term Structure) |
| Household | MICH (1yr) | FRED (Michigan Survey) |
| Household | SCE 1/3/5yr median | NY Fed Survey of Consumer Expectations |
| Professional | CPI/PCE 1/5/10yr | Philadelphia Fed SPF |
| Professional | CPI 10yr (semiannual) | Philadelphia Fed Livingston Survey |
| Business | Year-ahead unit costs | Atlanta Fed BIE (**optional**, public chart data only) |
| Communications | Board speeches (1996-present) | federalreserve.gov |
| Communications | FOMC minutes + statements | federalreserve.gov |
| Macro controls | CPI/PCE/UNRATE/payrolls/GDP/yields/FFR/oil/NFCI | FRED |

**Deliberately excluded:** the Michigan 5-10yr long-run series has no lawful
machine-readable public endpoint (subscription data); it is documented in
`config/sources.yaml` as unavailable rather than silently substituted.

## Information-set alignment (the core correctness requirement)

For every Fed communication at time *t*, every regressor must reflect
information *actually public strictly before t* -- never an observation's
reference period. `src/features/align_information_set.py` enforces this via
`asof_merge_strict` (`src/utils/dates.py`) with `strict=True` everywhere. Because
every event and every daily-market observation in this project is stored as a
date-only timestamp, strict inequality automatically implements "use the prior
market close, not today's" for same-day speeches -- documented in the module's
docstring, not a special case bolted on separately.

Release dates are **exact** where an official calendar exists (SPF's
`spf-release-dates.txt`, the FOMC calendar's stated minutes-release dates) and
**transparently reconstructed** where none does (NY Fed SCE, ATSIX, Atlanta BIE,
several FRED series, macro-control publication lags) -- every reconstructed row
carries a `release_date_estimated=True` flag; see each `src/data/*.py` module's
docstring for the specific rule and its evidence.

## Known limitations

- **Fed Board speech coverage.** federalreserve.gov's speech archive covers
  Board Governors reliably; it is *not* a comprehensive archive of the 12
  regional Reserve Bank presidents, who publish independently. This is a real
  selection issue for any "the Fed's" communication claim. The architecture
  (one adapter per source) supports adding bank-specific scrapers later.
- **FOMC statement coverage before ~2000** is sparse by design, not a scraping
  gap -- the Committee did not issue a statement after every meeting until
  around 2000.
- **1993-1995 FOMC minutes** are not retrievable in the web-published HTML
  format this project parses; verified empirically against the live archive,
  not assumed.
- **One speaker-attribution edge case:** a small number of Randal K. Quarles
  documents are split across two `speaker` values ("Randal K. Quarles" and
  a mis-parsed compound-title variant) because his bio title included a
  secondary board-chair role our role/name regex doesn't fully disambiguate.
  Affects <0.5% of the speech corpus; noted here rather than silently fixed
  with a lossy heuristic.
- **The multivariate 21-measure leave-one-out exercise (Figure 6)** is noisy:
  with 21 highly correlated regressors and a few hundred observations, some
  measures show a *positive* incremental OOS R^2 (removing them improves
  fit), an overfitting artifact of joint estimation rather than a
  substantive finding. The univariate (Table 4), family-level (Table 6),
  and robustness (Table 8) results are more stable and should be weighted
  more heavily -- this asymmetry is itself discussed in
  `output/research_summary.md`.
- **Transformer models B/C were benchmarked on the 400-sentence annotation
  sample, not the full corpus** (a CPU-only `facebook/bart-large-mnli` pass
  over ~1,900 documents' sentences would take many hours in this
  environment). The dictionary model (Model A) is what every table in
  `output/` is built from; B/C exist as validated, documented alternatives
  ready to run at scale on GPU hardware.

## Transformer stance models (optional)

Models B (zero-shot NLI) and C (FinBERT) require `torch`+`transformers`:

```bash
pip install -e ".[nlp]"
python scripts/run_nli_benchmark.py   # scores the annotation sample, not the full corpus
```

**Platform note:** PyTorch dropped Intel-macOS wheels after 2.2.x, which needs
numpy's pre-2.0 ABI, while this project's default `scipy`/`scikit-learn` pins
need numpy>=2. `pyproject.toml`'s `[nlp]` extra documents and resolves this
(pinning the whole stack down) for Intel Mac; on Linux/Apple Silicon/Windows
the ceiling can be relaxed.

Benchmark result on this project's real annotation sample: dictionary (A) and
NLI (B) agree moderately (r=0.44); FinBERT (C) correlates weakly with both
(r=-0.10, r=-0.18) -- empirical confirmation that financial sentiment is not
the same construct as monetary-policy stance (spec's explicit warning against
conflating the two).

## Human annotation validation

`data/annotation/stance_annotation_sample.csv` is a 400-sentence sample
stratified by decade x document-type x model-predicted-label (15% speaker cap),
with blank `human_label`/`human_confidence` columns. After manual labeling, run:

```python
import pandas as pd
from src.text.annotation import score_annotations
labeled = pd.read_csv("data/annotation/stance_annotation_sample.csv")
report = score_annotations(labeled)  # accuracy, macro F1, confusion matrix, Spearman rho
```

The spec's stated methodology is to choose the primary stance model by
validation performance against these labels, not by convenience -- this
pipeline currently reports Model A (dictionary) throughout because it is the
one validated at full-corpus scale; re-running `score_annotations` after
labeling is the documented next step to potentially revise that choice.

## Testing

```bash
pytest                          # full suite, includes live network smoke tests
pytest -m "not network"         # offline unit/synthetic-data tests only (181 tests, ~5s)
```

Network tests hit real external services (FRED, federalreserve.gov, Philadelphia/
NY/Atlanta Fed) and validate the actual current schema of each source, not just
mocked responses -- several were essential in catching real upstream format
changes (SPF's malformed SAS-export XML timestamps, three different FOMC
statement/minutes URL schemes since 1996, Michigan/legacy-speech HTML
templates) during development.

## Limitations and identification caveats

Every coefficient in this project is a **predictive association conditional on
lagged information and macro controls**, never a causal effect estimate. Live
concerns, discussed inline in the relevant modules rather than only here:

- Inflation expectations react to inflation data; the Fed reacts to both.
- Fed rhetoric can itself move market-based expectations (addressed partially
  by prior-close alignment, not fully).
- Speeches are not randomly scheduled treatments.
- Officials and forecasters observe common macro shocks the panel's control
  set cannot fully span.

No specification here claims to have identified the Fed's structural reaction
function. Section 24 of the original spec and the docstrings in
`src/models/event_study.py` and `local_projections.py` discuss this further.

## Reproducing from empty data/

Every script in `scripts/` is idempotent and cache-aware (`src/utils/cache.py`
persists raw responses with sha256 + timestamp provenance under `data/raw/`,
skipped on re-run unless `--force-refresh` is passed where supported). Deleting
`data/` entirely and re-running `01` through `08` in order reproduces every
table and figure in `output/` from scratch.
